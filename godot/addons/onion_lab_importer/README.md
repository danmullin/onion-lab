# Onion Lab Importer (Godot 4)

1. Copy the `addons/onion_lab_importer` folder into your Godot project `res://addons/`.
2. Project → Project Settings → Plugins → enable **Onion Lab Importer**.
3. Copy the exported `.png` + `.onionlab.json` into `res://` (same folder).
4. Project → Tools → **Onion Lab: Import JSON…** and pick the JSON.

Creates `.spriteframes.tres` and a sample `.tscn` with AnimatedSprite2D beside the JSON.
